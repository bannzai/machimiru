このディレクトリの *.geojson のライセンスと出典

このディレクトリの *.geojson は、OpenPOI API (https://openpoiapi.com/attribution.html) の施設の検索結果を machimiru が加工したものです。
施設名・座標・ライセンス・出典表示だけを残し、東京都の 62 区市町村の境界の外の施設を除き、名前と座標が同じ施設を 1 件にまとめ、施設がある区市町村のコードを足しています。
施設ごとのライセンスは各レコードの licenses、出典表示は attributions にあります。各ライセンスの条件は次のとおりです。

- CDLA-Permissive-2.0: Community Data License Agreement - Permissive - Version 2.0。本文は LICENSE-CDLA-Permissive-2.0.txt (https://cdla.dev/permissive-2-0/)。出典表示は Overture Maps Foundation, overturemaps.org
- Apache-2.0: Apache License, Version 2.0。本文は LICENSE-Apache-2.0.txt (https://www.apache.org/licenses/LICENSE-2.0)。Foursquare Labs, Inc. の Foursquare OS Places 由来のレコードは NOTICE-Foursquare.txt を一緒に配布します
- CC BY 4.0: クリエイティブ・コモンズ・ライセンス 表示 4.0 国際 (https://creativecommons.org/licenses/by/4.0/deed.ja)
- 公共データ利用規約（第1.0版, PDL1.0）: 公共データ利用規約 第 1.0 版 (https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)
