# デザインのモック (関門 2)

関門 2 ( https://github.com/bannzai/machimiru/issues/14 ) で見せた画面のモック。Claude Design の artboard を素の HTML に書き出したもので、各ファイルをブラウザで直接開ける (ビルド・サーバーは要らない)。地図は見本の図形、`[件数]` のような値はレイアウトの見本で、実データではない。

| ファイル | 画面 |
| --- | --- |
| `main.html` | 開いた直後。探している暮らしを文章で書く欄 |
| `chat.html` | 文章を「子育て・通勤・予算・買い物」の軸に分けた結果。軸ごとに外す・直す・足す |
| `matrix.html` | まとめ。選んだ街 × 軸の表と、全部の軸を合わせた塗り分けの地図 |
| `compare.html` | 軸のタブを切り替えると、地図の塗り分けと一覧がその軸の内容に変わる |
| `pins.html` | 選んだ軸に対応する施設 (子育てなら保育園と小児科) のピン |
| `town.html` | 街の詳細。軸ごとの段階と根拠の数値、個別の制度へのドリルダウン、物件サイトへの導線 |
| `desktop.html` | PC 幅。左に軸の一覧と街 × 軸の表、右に地図 |

モバイルの画面は 390 × 844 px の枠で描いている。画面間のリンクは同じディレクトリのファイルを指すが、モックは状態ごとに 1 ファイルの静止画で、状態を持たない。次は見本の代表 1 つに固定していて、リンクを押しても押した対象の状態にはならない:

- 軸のタブ (通勤・予算・買い物) はどれも `compare.html` (子育ての軸を表示) を開く
- 街の行 (新宿区・目黒区) はどれも `town.html` (中野区の詳細) を開く
- `#sources` (データの出典)・`#programs` (子育て支援制度の一覧) は、まだモックの無い画面へのリンクの置き場所で、飛び先は無い
- 物件サイトへのリンクは SUUMO のトップを指す。実装では選んだ区市町村と家賃・広さを付けた検索結果 URL になる (`documents/PROJECT.md`「物件サイトとの関係」)

## 配色と書体

- 背景 `#F3F5F4` (青みのある薄いグレー)、文字と主ボタン `#17212B` (濃紺)、リンク `#1D5FBF`
- 合う度合いの 4 段階 `#DCE9E2` → `#A9CDBD` → `#5FA58B` → `#1F6B55`
- 施設のピン: 保育園 `#1D5FBF` の丸、小児科 `#B84E08` の四角
- 書体は Zen Kaku Gothic New (Google Fonts)。読み込めない環境では Hiragino Sans にフォールバックする
