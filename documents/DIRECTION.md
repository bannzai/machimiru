# 方向性: machimiru

## 仮説

遠方から東京への引っ越しを検討している子育て世帯 (最初の利用者は bannzai 本人) は、土地勘が無い状態で、保育園・小児科などの周辺施設と自治体の子育て施策をエリアをまたいで見比べる手段が無い。地図上でエリアを複数選び、施設の色分けと施策の濃淡を 1 画面に重ね、自然言語から施設の種類の候補を出せば、住むエリアの候補を絞れる。

## 判定基準

公開前は関門 3 (触れる版) で、bannzai 本人が自分の候補エリアを比べるのに使えるかを判断する。公開後は下の表で判定する。

## 必要な機能

関門 1 (構想) の返答 (2026-10-04) を反映した一覧。対象地域は東京都。

- [ ] 地図の表示と、エリアの階層選択 (都道府県 → 市区町村 → 町丁。ズームで切り替わり、複数選択できる)
- [ ] 施設マーキング (キーワードを入れると候補が出て、キーワードごとに色を変えたピンで地図に重なる)
- [ ] 子育て施設の種類での表示 (保育所・小児科・産婦人科などを、行政のオープンデータから種類で選んで出す)
- [ ] 街ごとの子育てのしやすさの提示 (条件に合う街か、総合的に子育てがしやすい特色がありそうかを区市町村ごとに示し、個別の制度はそこからドリルダウンして見る。見せ方は色分けに限らない)
- [ ] チャットからの絞り込み (自然言語の入力から、施設の種類の候補をチェックボックスで出し、チェックした種類をピンで表示する)
- [ ] 物件の条件での絞り込み (選んだエリアと家賃・広さの条件で物件を探す。物件サイトの検索結果を開くリンクにするか、物件データを取得して画面に出すかは未確定)
- [ ] データの出典の表示
- [ ] 検索結果・SNS 向けのページ情報 (タイトル・説明文・OGP 画像・sitemap)
- [ ] 配信とアクセス解析 (Cloudflare Workers と Cloudflare Web Analytics。関門 3 の後に有効にする)
- [ ] iOS アプリ (SwiftUI の殻 + WebView。Web の公開後)

## デザインの方向

- 入口は文章 1 つ。探している暮らしを自然言語で受け取り、AI が「子育て・通勤・予算・買い物」のような軸に分ける。分け方は利用者が直せる
- 軸はタブで切り替える。切り替えると地図の塗り分け・街の一覧・施設のピンが全部その軸の内容になる。「まとめ」は全部の軸を合わせた見え方
- 街 × 軸の表で、1 つの街がどの軸に合い、どの軸に合わないかを 1 行で読めるようにする。データが無い軸は「データなし」と出す
- 見た目は地図帳や路線図のような、線と面で読ませる実用寄り。パステルやイラストには寄せない
- モックは `documents/design/mockups/` (ブラウザで直接開ける HTML)。最終の確認は関門 2 ( https://github.com/bannzai/machimiru/issues/14 ) で待っている
