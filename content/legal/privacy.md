# プライバシーポリシー

bannzai（以下「提供者」といいます。）は、提供者の提供するサービス「machimiru」（以下「本サービス」といいます。）における、ユーザーについての個人情報を含む利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

## 収集する利用者情報および収集方法
本ポリシーにおいて、「利用者情報」とは、ユーザーの識別に係る情報、通信サービス上の行動履歴、その他ユーザーまたはユーザーの端末に関連して生成または蓄積された情報であって、本ポリシーに基づき提供者が収集するものを意味するものとします。

本サービスは、アカウント登録の機能を提供しておらず、氏名、住所、電話番号、メールアドレスの入力を求めません。

### ユーザーが検索欄・チャット欄に入力する文章
ユーザーが検索欄またはチャット欄に入力した文章（以下「入力内容」といいます。）は、次のとおり送信されます。提供者は、入力内容を提供者のサーバーに保存しません。入力内容には、個人を特定できる情報を含めないでください。

- 検索欄に入力した語は、施設の検索のために、ユーザーの端末から後記「利用する外部サービス」の OpenPOI API へ直接送信されます。提供者のサーバーを経由しません。
- チャット欄に入力した文章は、ユーザーの入力に合う施設の種類その他の候補の提示のために、提供者のサーバーおよび後記「利用する外部サービス」の事業者へ送信されます。

### 地図の表示範囲と選択した地域
地図の表示および施設の検索のために、ユーザーが表示している地図の範囲、選択した地域および検索の条件が、後記「利用する外部サービス」の事業者へ送信されます。施設の検索では、地域を選択している場合は選択した地域を囲む範囲が、選択していない場合は表示している地図の範囲が、検索の語と一緒に OpenPOI API へ送信されます。子育て施設の種類での表示は、本サービスが配信するデータの中から探すため、選んだ種類や範囲を外部へ送信しません。本サービスは、ユーザーの端末の位置情報（GPS 等）を取得しません。

### ユーザーの端末に保存する情報
本サービスは、選択した地域、検索の条件、表示の設定を、ユーザーの端末のブラウザのストレージ（localStorage 等）に保存することがあります。これらの情報はユーザーの端末にのみ保存されます。

### ユーザーがお問い合わせで送信する情報
- お問い合わせでご連絡いただくメールアドレス、お名前（記載がある場合）および本文

### 提供者または委託先が自動的に収集する情報
本サービスへのアクセスに伴い、以下の情報が、本サービスの配信、地図の表示、施設の検索およびアクセス解析に利用する外部サービスによって記録されることがあります。

- IP アドレス
- ブラウザの種類・バージョン、オペレーティングシステム等の端末情報
- リファラ（参照元の URL）
- 閲覧したページの URL、閲覧日時

### アクセス解析
本サービスは、利用状況の把握と改善のために Cloudflare, Inc. が提供する Cloudflare Web Analytics を利用します。取得されるのは、ページの表示回数、参照元、国、ブラウザの種類等の集計情報であり、個々のユーザーを特定するものではありません。入力内容はアクセス解析に送信されません。詳細は Cloudflare 社のプライバシーポリシー（ https://www.cloudflare.com/privacypolicy/ ）をご確認ください。

### Cookie 等
本サービスは Cookie を使用しません。前記の端末への保存には、ブラウザのストレージを使用します。

### 外部サイトへのリンク
本サービスからのリンクで開く、提供者以外の者が運営するウェブサイト（賃貸物件の情報サイトを含みます。）での情報の取扱いは、各サイトのプライバシーポリシーによります。

## 利用目的
利用者情報の具体的な利用目的は以下のとおりです。

1. 本サービスの提供、維持、保護および改善のため
1. 本サービスの利用状況の分析および統計データの作成のため
1. 本サービスに関するご案内、お問い合わせ等への対応のため
1. 本サービスに関する提供者の規約、ポリシー等（以下「規約等」といいます。）に違反する行為に対する対応のため
1. 本サービスに関する規約等の変更などを通知するため

## 保存期間
- 入力内容は、提供者のサーバーに保存しません。
- お問い合わせでいただいたメールアドレスおよび本文は、対応の完了後 1 年間保存し、その後削除します。
- 後記の外部サービスが記録する情報の保存期間は、各事業者の定めによります。
- ユーザーの端末に保存する情報は、ユーザーが削除するまで端末に残ります。

## 削除の方法
- ユーザーの端末に保存した選択した地域・検索の条件・表示の設定は、ブラウザの設定から本サイトのサイトデータ（Cookie とサイトデータ）を削除することで、いつでも消去できます。
- お問い合わせでいただいた情報の削除は、下記のお問い合わせ窓口へメールでご依頼ください。ご本人からのご依頼であることを確認のうえ、遅滞なく削除します。

## 利用する外部サービス
本サービスの提供にあたり、提供者は以下の外部サービスを利用しています。これらのサービスの利用に伴い、利用者情報の取扱いの一部をこれらの事業者に委託し、または利用者情報がこれらの事業者のサーバーに送信もしくは保存されることがあります。

| 事業者・サービス | 用途 | 送信される情報 | プライバシーポリシー・利用条件 |
|---|---|---|---|
| Cloudflare, Inc.（Cloudflare Workers） | サイトの配信、提供者のサーバーでのチャット欄の入力内容の処理 | チャット欄の入力内容、自動的に収集する情報 | https://www.cloudflare.com/privacypolicy/ |
| Cloudflare, Inc.（Cloudflare Web Analytics） | アクセス解析 | 閲覧したページの URL、参照元等 | https://www.cloudflare.com/privacypolicy/ |
| OpenFreeMap | 地図の表示 | 地図の表示範囲、自動的に収集する情報 | https://openfreemap.org/privacy/ |
| OpenPOI API | 施設の検索 | 検索の語、地図の表示範囲または選択した地域を囲む範囲、自動的に収集する情報 | https://docs.openpoiapi.com/legal.html |

## 外国にある第三者への提供
前項の事業者には日本国外に所在する者が含まれ、これらのサービスの利用に伴い、利用者情報が日本国外のサーバーに送信または保存されることがあります。各事業者における情報の取扱いは、前項の表に記載した各事業者のプライバシーポリシー・利用条件によります。

## 第三者提供
提供者は、利用者情報のうち、個人情報については、あらかじめユーザーの同意を得ないで、第三者（日本国外にある者を含みます。）に提供しません。ただし、次に掲げる必要があり第三者（日本国外にある者を含みます。）に提供する場合はこの限りではありません。

1. 提供者が利用目的の達成に必要な範囲内において個人情報の取扱いの全部または一部を委託する場合
1. 合併その他の事由による事業の承継に伴って個人情報が提供される場合
1. 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、ユーザーの同意を得ることによって当該事務の遂行に支障を及ぼすおそれがある場合
1. その他、個人情報の保護に関する法律（以下「個人情報保護法」といいます。）その他の法令で認められる場合

## 個人情報の開示・訂正・利用停止・消去
提供者は、ユーザーから、個人情報保護法の定めに基づき個人情報の開示・訂正・利用停止・消去を求められたときは、ユーザーご本人からのご請求であることを確認の上で、遅滞なく対応します（当該個人情報が存在しないときにはその旨を通知いたします。）。ただし、個人情報保護法その他の法令により提供者が義務を負わない場合は、この限りではありません。

## 安全管理措置
提供者は、利用者情報の漏えい、滅失または毀損の防止その他の安全管理のために必要かつ適切な措置を講じます。具体的には、入力内容を保存しない設計、アクセス権限の限定、通信の暗号化、外部サービスの認証情報の管理等を行います。
