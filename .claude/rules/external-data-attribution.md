# 外部データは出典を表示し、ライセンス情報と一緒に保存する

machimiru が画面に出す施設・行政区域・自治体の施策の情報は、すべて外部の公開データに由来する。提供元ごとに出典表示とライセンスの義務があり、表示を落とすと規約違反になる。

- 外部データを新しく取り込む時は、提供元・ライセンス・出典表示の文言・取得日を `documents/PROJECT.md`「データの出典」の表に足す。表に無い提供元のデータを画面に出さない
- 画面に出す時は、その画面から到達できる場所に出典を表示する。OpenPOI API の結果は「出典として OpenPOI API を記載し、出典・ライセンスページへリンク」が条件 ( https://docs.openpoiapi.com/ の FAQ、2026-10-04 確認)。地図タイルは MapLibre の attribution コントロールを消さない
- 外部 API のレスポンスを保存する時は、レスポンスに含まれるライセンス・出典のフィールド (OpenPOI API なら `licenses` と `attributions`) をレコードと一緒に保存する
- 自治体の公開データを加工して出す時は、自治体が発信した情報に見える書き方をしない (東京都の子育て支援制度レジストリの利用条件。 https://www.metro.tokyo.lg.jp/information/press/2024/11/2024112807 )
